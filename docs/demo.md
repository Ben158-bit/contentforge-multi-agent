# 端到端演示流程

本文档给出一个可完整演示的示例：从创建任务到人工确认定稿，全程约 1-2 分钟
（演示模式 FakeLLM，无真实 API 调用；真实 DeepSeek 模式约 1-3 分钟，取决于模型响应）。

## 准备

```bash
# 终端 1：后端（演示模式，无需 API Key）
cd backend
FAKE_LLM=true ../.venv/Scripts/python -m uvicorn app.main:app --port 8000

# 终端 2：前端
cd frontend
npm run dev
```

打开 http://localhost:5173

## 演示步骤

### 1. 新建任务

填写表单（示例值）：

- **营销主题**：智能保温杯新品上市推广
- **目标渠道**：小红书
- **品牌/产品名**：暖芯
- **目标受众**：25-35 岁都市白领
- **附加要求**：突出 24 小时长效保温，价格亲民

点击「启动多 Agent 流水线」。

### 2. 观察流水线执行

任务详情页的流水线视图会**实时点亮**各阶段（SSE 推送）：

1. **市场调研** ✅ → 行业趋势/受众洞察/痛点/关键词
2. **竞品分析** ✅ → 竞品矩阵与差异化机会点
3. **策略制定** ✅ → 核心主张/内容角度/语调指南
4. **文案创作** ✅ → 小红书风格文案变体
5. **审校优化** 🔁 → **演示模式第一次审校不通过**，打回创作带反馈重写 → 第二次通过

> 演示模式故意让审校第一次打回，展示「审校-创作」循环与反馈注入机制。
> 页面顶部横幅提示：**⏸ 流水线已暂停，等待你审阅并确认/编辑下方文案后继续。**

### 3. 人工确认（human-in-the-loop）

此时流水线在 `human_confirm` 节点**暂停**（LangGraph `interrupt`），你可以：

- **编辑阶段产出**：例如打开「策略制定」卡片点「编辑」，修改核心价值主张后保存
- **编辑文案变体**：直接修改标题/正文/话题标签

点击「✓ 确认定稿并完成」→ 任务状态变为**已完成**，工件持久化到 SQLite。

### 4. 查看统计

回到任务列表页：成本（¥0.0042 级别）、耗时、完成数实时汇总。

### 5. 重新生成

任务详情页点「重新生成」→ 重置 checkpoint 后整个流水线重新执行
（观察流水线视图从零开始再次点亮）。

## 预期输出示例（演示模式）

| 阶段 | 关键产出 |
|---|---|
| 调研 | 趋势：健康化消费升级；痛点：同质化严重、保温效果存疑 |
| 竞品 | 机会点：『24 小时长效保温 + 亲民价格』组合尚未被主打 |
| 策略 | 核心主张：一杯暖芯，24 小时暖到你心里 |
| 文案 | 标题：打工人冬日续命神器｜实测 24h 保温杯 |
| 审校 | 第一次反馈：缺少行动号召 → 第二次通过 |

## 切换到真实 DeepSeek

```bash
cd backend
cp .env.example .env   # 填入真实 DEEPSEEK_API_KEY
../.venv/Scripts/python -m uvicorn app.main:app --port 8000
```

无需改前端代码，任务将调用真实 DeepSeek API，成本/耗时统计随之真实化。
